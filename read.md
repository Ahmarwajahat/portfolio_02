# Netlify Deployment Guide & Environment Variables

This document outlines everything you need to successfully deploy your portfolio application using Netlify (Frontend + Serverless Backend).

## 🌍 Environment Variables to Add in Netlify

Netlify requires environment variables to securely connect your app to Firebase and Supabase. Since this project is configured to build the frontend and serve backend API endpoints via Netlify Functions, you will need to specify **BOTH** sets of environment variables in your Netlify site configuration.

### 🎨 Frontend (React / Vite) Environment Variables
*Find these in your `frontend/.env` file. These connect the user-facing admin portal to Firebase.*
1. `VITE_FIREBASE_API_KEY`: e.g., `AIzaSyAJ...`
2. `VITE_FIREBASE_AUTH_DOMAIN`: e.g., `portfolio-b6378.firebaseapp.com`
3. `VITE_FIREBASE_PROJECT_ID`: e.g., `portfolio-b6378`
4. `VITE_FIREBASE_STORAGE_BUCKET`: e.g., `portfolio-b6378.firebasestorage.app`
5. `VITE_FIREBASE_MESSAGING_SENDER_ID`: e.g., `50630869...`
6. `VITE_FIREBASE_APP_ID`: e.g., `1:50630869...`
7. `VITE_API_URL`: `/api` *(Important: Keep it exactly as `/api` for production so it routes appropriately into Netlify Functions. Locally, it is set to `http://localhost:5000/api`)*

### ⚙️ Backend Environment Variables
*Find these in your `backend/.env` file. These connect your API (Netlify Functions) to your database & admin auth provider.*
8. `SUPABASE_URL`: e.g., `https://your-project.supabase.co`
9. `SUPABASE_SERVICE_ROLE_KEY`: Your private Supabase service role key (it usually starts with `eyJhbG...`).
10. `FIREBASE_SERVICE_ACCOUNT_JSON`: Your full Firebase Admin SDK service account JSON object. *Tip: Netlify supports multi-line variables, so you can paste the raw JSON exactly as generated by Firebase.*
11. `NODE_ENV`: `production`

## 🚀 How to Fill This Out in Netlify (Step-By-Step)

### Step 1: Connect your Repository
1. Go to your [Netlify Dashboard](https://app.netlify.com).
2. Click **"Add new site"** -> **"Import an existing project"**.
3. Choose **GitHub** and authorize it if necessary.
4. Select your portfolio repository from the list.

### Step 2: Configure Build Settings
You actually **do not** need to edit the build settings manually because we have provided a `netlify.toml` file in the root folder! Netlify will read this file automatically and pre-fill everything.

If Netlify ever asks you to confirm, verify it looks exactly like this:
- **Base directory:** *(Leave Empty)*
- **Build command:** `npm install --prefix backend && npm install --prefix frontend && CI=false npm run build --prefix frontend`
- **Publish directory:** `frontend/dist`
- **Functions directory:** `backend/functions`

### Step 3: Add the Environment Variables
Before you finalize deployment, scroll down and click **"Add environment variables"**.
1. Click **"Add a variable"** -> **"Add a single variable"**.
2. Type in the Key (e.g. `VITE_FIREBASE_API_KEY`) and its Value.
3. Repeat this process until **all 11 environment variables** listed above are added to Netlify!

**Special Focus on `FIREBASE_SERVICE_ACCOUNT_JSON`:**
* When pasting the service account JSON, make sure the string correctly matches your `backend/.env` without accidentally cutting off the `{` or `}`. 

### Step 4: Deploy and Test
1. Click **"Deploy Site"**.
2. Netlify will begin downloading your libraries, building the React app, and bundling your Express backend into a Serverless Function!
3. Wait approximately 2–3 minutes. Once it says "Published," click the link to visit your live site.
4. Navigate to `/admin`, log in, and confirm you can add, edit, and read your portfolio content ✨.
